如何找到 M3U8 链接 — 完整教程

M3U8 链接是下载流媒体视频的钥匙。这篇教程教你用浏览器自带的开发者工具找到它，无需安装任何额外软件。

什么是 M3U8 链接？

M3U8 链接是以 .m3u8 结尾的网络地址，指向一个 HLS 播放列表。这个播放列表告诉播放器视频分片段在哪里。大多数流媒体网站都使用 HLS 技术，找到了 M3U8 链接，就找到了完整的视频。

典型格式：https://example.com/videos/stream_720p.m3u8

方法一：Chrome 开发者工具（推荐）

  1. 打开视频页面，开始播放视频
  2. 按 F12（或 Ctrl+Shift+I）打开开发者工具
  3. 点击顶部的 Network（网络）选项卡
  4. 在搜索框中输入 m3u8
  5. 刷新页面，重新播放视频——会看到 .m3u8 文件出现在列表中
  6. 右键点击该条目 → Copy → Copy link address
  7. 将链接粘贴到我们的转换工具中

提示：如果看到多个 .m3u8 文件，选含数字如 720、1080 的那个——那是具体分辨率的子播放列表。

方法二：Firefox 开发者工具

  1. 打开视频页面，开始播放
  2. 按 F12
  3. 点击 Network（网络）选项卡
  4. 搜索框输入 m3u8
  5. 刷新页面，M3U8 地址会出现在列表中
  6. 右键链接 → Copy → Copy URL

方法三：Edge 浏览器

  1. 打开页面并播放视频
  2. 按 F12 或 Ctrl+Shift+I
  3. 进入 Network（网络）选项卡
  4. 搜索 m3u8
  5. 找到 .m3u8 条目，右键复制链接地址

常见问题

网络选项卡中没有出现 .m3u8 文件 ▾

试试这些方法：

  • 确保视频正在播放——暂停状态可能不会发起新请求
  • 清空网络列表后刷新页面重新播放
  • 搜索 .ts 代替——视频分片文件，观察其请求规律推测 M3U8 地址
  • 部分网站使用 DRM 加密保护——这类视频无法转换
看到的是"主播放列表"——该用哪个？ ▾
主播放列表包含多个清晰度的链接。你需要子播放列表（某个具体分辨率的链接）。找含数字如 720、1080、480 的地址。不确定的话，逐个尝试——我们的工具会自动识别。
M3U8 链接失效或过期了 ▾
有些网站使用时效性令牌——M3U8 链接只有几分钟有效期。复制链接后需要立即使用。如果返回"403 Forbidden"或空白内容，说明链接已过期。
DRM 加密的视频能转吗？ ▾
不能。DRM 加密视频（如 Netflix、Disney+、爱奇艺等）无法转换。本工具仅适用于标准的、未加密的 HLS 流。绕过 DRM 在大多数地区属于违法行为。

准备开始？

有了 M3U8 链接，去转换工具粘贴即可下载 MP4。
