M3U8在线工具使用教程

教你使用我们的一站式 M3U8 工具：在线播放、下载视频、合并 TS 分片、转换 MP4。

功能一：在线播放 M3U8 视频

不需要下载任何软件，直接在浏览器中播放 M3U8/HLS 流媒体视频。

  1. 打开 在线转换页面
  2. 将 M3U8 链接粘贴到输入框中（例如 https://example.com/video.m3u8）
  3. 点击 ▶ Play（播放）按钮
  4. 视频会加载到内置播放器中，支持全屏、音量调节、进度拖拽

注意：播放依赖浏览器的 HLS 支持。推荐使用 Chrome、Edge 或 Firefox 最新版。部分跨域资源需要 CORS 代理中转，工具已自动处理。

功能二：下载 M3U8 视频（TS 分片）

将整个 M3U8 视频的所有分片下载到本地，方便离线观看或进一步处理。

  1. 粘贴 M3U8 链接到输入框
  2. 点击 Download（下载）按钮
  3. 工具会自动解析播放列表，逐个下载所有 .ts 分片文件
  4. 下载完成后，工具会自动合并为一个 .ts 文件并触发下载

下载后的 .ts 文件可直接用 VLC Media Player 或 PotPlayer 打开播放。

功能三：拖拽合并本地 TS 文件

如果你已经有了一批 .ts 分片文件（比如通过其他方式下载的），可以用拖拽合并功能：

  1. 在工具页面找到 拖拽区域
  2. 将所有 .ts 文件从文件夹中拖入（或点击区域选择文件）
  3. 工具会自动按文件名排序并合并为一个完整文件
  4. 点击下载按钮保存合并后的视频

提示：确保文件名按播放顺序排列（通常包含序号如 001.ts、002.ts），合并结果才正确。

功能四：TS 转 MP4（需要 FFmpeg）

下载或合并后的 TS 文件可以通过 FFmpeg 无损转为通用 MP4 格式：

ffmpeg -i "视频.ts" -c copy -bsf:a aac_adtstoasc "输出.mp4"
  • -c copy 表示直接复制编码，不重新压缩，10 秒内完成且画质无损
  • -bsf:a aac_adtstoasc 处理 AAC 音频，确保 MP4 兼容性

详细 FFmpeg 安装和批量转换教程参见：TS 转 MP4 完整教程。

常见问题

点击播放后没有反应？ ▾
  • 检查 M3U8 链接是否正确（必须以 .m3u8 结尾或包含 m3u8 路径）
  • 确认链接没有过期——部分网站的 M3U8 链接有时效性
  • 检查浏览器控制台（F12 → Console）是否有报错信息
  • 尝试用 Download 代替 Play——下载合并后再播放
下载进度卡住不动了？ ▾
  • TS 分片数量可能很多（几百个），需要耐心等待
  • 某个分片请求失败——工具会自动重试 3 次
  • 网络不稳定导致超时——刷新页面重试
  • 如果反复失败，可能是目标服务器限制了跨域访问
合并后的视频没有声音？ ▾
部分 HLS 流将音频和视频分离在不同的分片中。我们的工具会合并所有分片，但若源流本身就是音视频分离的，建议用 FFmpeg 进一步处理。参见 TS 转 MP4 教程。
不知道 M3U8 链接在哪里？ ▾
参见我们的 M3U8 链接查找教程，教你用浏览器开发者工具轻松获取任何网站的 M3U8 地址。
