关于我们

我们的使命

我们打造了这款免费 M3U8 转 MP4 工具，让视频格式转换变得简单、快捷、无需安装任何软件。只需粘贴链接，就能获得 MP4 文件。

为什么做这个

M3U8（HLS）是互联网上最常用的流媒体格式之一，几乎所有视频网站都在使用。但普通播放器无法直接播放 M3U8 文件，而且市面上大多数转换工具都需要安装复杂的软件。

我们利用 WebAssembly 技术，把完整的视频处理引擎搬到了浏览器里。不需要上传文件、不需要服务器处理，一切都在你的设备上完成。

原理

我们的转换器使用的是 FFmpeg——业界标准的视频处理库，通过编译为 WebAssembly 在浏览器中运行：

  1. 获取并解析 M3U8 播放列表，找到所有视频分片
  2. 通过代理下载每个 .ts 分片文件
  3. FFmpeg 将所有分片合并为一个完整的 MP4 文件
  4. MP4 文件准备好供下载——全程在你的设备上完成

隐私至上

你的视频文件不会离开你的设备。和很多"在线转换器"不同，我们的工具完全在浏览器本地处理。这意味着：

  • 没有文件上传——数据始终在你的电脑上
  • 没有服务器处理——我们根本看不到你的视频
  • 没有存储——不会保存任何数据

技术栈

  • FFmpeg.wasm — FFmpeg 的 WebAssembly 版本，浏览器端视频处理
  • Cloudflare Workers — 边缘 CORS 代理，保证分片下载稳定
  • Cloudflare Pages — 全球 CDN 加速，访问快人一步
  • 纯 HTML/CSS/JavaScript — 无臃肿框架，极致轻量
