FFmpeg 批量转换视频完整教程（批处理脚本）

发布：2026年5月  |  适用：Windows / Mac / Linux

为什么需要批量转换？

手上有十几个甚至几十个视频需要转换格式、压缩大小或者统一编码？一个一个手动输入命令不仅效率低下，还容易出错。FFmpeg 提供了强大的批处理能力，通过简单的脚本可以一键处理整个文件夹的视频。本教程将介绍三种最实用的批量转换方案。

方案一：Windows 批处理脚本

批量将 TS 转为 MP4

这是最常见的需求——从网上下载了一批 TS 分片文件，需要逐个转为 MP4。在视频目录创建 convert.bat 文件，内容如下：

@echo off
for %%i in (*.ts) do (
    ffmpeg -i "%%i" -c copy -bsf:a aac_adtstoasc "%%~ni.mp4"
)
echo 所有转换完成！
pause

将 convert.bat 放在 TS 文件所在的文件夹，双击运行即可。每处理完一个 TS 文件，就会在同目录生成一个同名的 MP4 文件。

批量压缩视频（减小文件体积）

如果需要将一批高清视频压缩为适合手机观看的小文件：

@echo off
mkdir compressed
for %%i in (*.mp4) do (
    ffmpeg -i "%%i" -vf scale=1280:720 -c:v libx264 -crf 23 -c:a aac -b:a 128k "compressed\%%i"
)
echo 压缩完成！
pause

参数说明：-vf scale=1280:720 缩放到 720p，-crf 23 控制画质（数值越小画质越好，18-28 为常用范围），-b:a 128k 设置音频码率。压缩后的文件在 compressed 文件夹中。

方案二：Mac / Linux Bash 脚本

批量转换视频格式

#!/bin/bash
for file in *.mkv; do
    ffmpeg -i "$file" -c copy "${file%.mkv}.mp4"
done
echo "All conversions done!"

保存为 convert.sh，运行 chmod +x convert.sh && ./convert.sh 即可。

递归处理子文件夹

如果视频分散在多个子文件夹中，使用 find 命令配合处理：

#!/bin/bash
find . -type f -name "*.ts" -exec sh -c '
    for file; do
        ffmpeg -i "$file" -c copy "${file%.ts}.mp4"
    done
' sh {} +

方案三：FFmpeg 内置批量功能

FFmpeg 的 concat demuxer 不仅能合并文件，配合脚本还能实现高效的批量处理。如果多个视频需要统一格式，可以用下面的写法：

ffmpeg -i input1.ts -i input2.ts -i input3.ts \
  -map 0 -c:v libx264 -c:a aac output1.mp4 \
  -map 1 -c:v libx264 -c:a aac output2.mp4 \
  -map 2 -c:v libx264 -c:a aac output3.mp4

这个命令一次性读入多个文件并分别输出，比多次启动 FFmpeg 更高效。

常用 FFmpeg 参数速查

参数作用示例
-c copy无损拷贝，不重新编码最快，无画质损失
-c:v libx264使用 H.264 编码器兼容性最好
-c:v libx265使用 H.265/HEVC 编码器文件更小，画质相当
-crf 23恒定质量参数18=高质量, 23=默认, 28=小文件
-preset编码速度ultrafast/fast/medium/slow
-vf scale=W:H缩放视频分辨率scale=1920:1080
-b:a 128k音频码率常见值 96k/128k/192k
-an移除音频轨道静音视频
-ss 00:01:00从指定时间开始裁剪视频开头
-t 00:00:30输出时长只取 30 秒

常见问题

批处理时个别文件报错怎么办？

在批处理脚本中加入错误检查。Windows 脚本中使用 if errorlevel 1 判断；Bash 脚本中使用 if [ $? -ne 0 ]。还可以将错误日志输出到文件：
ffmpeg -i "$file" -c copy "out.mp4" 2>> error.log

批量处理后如何自动删除原文件？

在处理完并确认输出无误后，可以在脚本末尾加上删除命令。但强烈建议先检查输出文件是否正常生成再删除：

# Bash 中先检查再删除
if [ -f "output.mp4" ] && [ -s "output.mp4" ]; then
    rm "original.ts"
fi

有没有图形化批量工具？

如果不想写脚本，可以用 HandBrake（免费开源，支持队列批量处理）或 Shutter Encoder（基于 FFmpeg，功能更全）。它们都有 Windows/Mac/Linux 版本，操作与 FFmpeg 命令逻辑一致。
