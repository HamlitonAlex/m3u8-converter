How to Merge TS Files — 3 Free Methods (Windows/Mac/Linux)

Published: May 2026  |  Reading time: 4 min

Why Merge TS Files?

When you download a streaming video, you often end up with dozens or hundreds of small TS segments instead of one continuous file. To watch the video smoothly or convert it to MP4, you need to combine these segments first.

Here are the three best free methods, ranked from easiest to most powerful.

Method 1: Use Our Online Downloader (Easiest — No Manual Work)

Our M3U8 downloader handles merging automatically. Paste the M3U8 URL, click Download, and you get a single merged TS file. No manual segment handling required.

This is the best option if you still have the original M3U8 playlist URL. Skip to the player page and let it do the work.

Method 2: FFmpeg Concatenation (Best Quality & Control)

FFmpeg can merge TS files with zero quality loss. First, create a text file listing all your segments:

Step 1: Create a file list

file 'segment_001.ts'
file 'segment_002.ts'
file 'segment_003.ts'
...

On Windows, generate this automatically in Command Prompt:

(for %i in (*.ts) do @echo file '%i') > filelist.txt

On Mac/Linux:

for f in *.ts; do echo "file '$f'" >> filelist.txt; done

Step 2: Run the merge

ffmpeg -f concat -safe 0 -i filelist.txt -c copy merged.ts

Step 3 (Optional): Convert to MP4

ffmpeg -i merged.ts -c copy -bsf:a aac_adtstoasc merged.mp4

The -c copy flag means no re-encoding — the merge takes seconds regardless of video length. Read our TS to MP4 guide for more conversion options.

Method 3: Binary Concatenation (No Software Install)

TS files can be merged with a simple copy command — no FFmpeg needed. This works because the TS format is designed for concatenation.

Windows:

copy /b segment_001.ts + segment_002.ts + segment_003.ts merged.ts

Or merge all TS files in a folder:

copy /b *.ts merged.ts

Mac / Linux:

cat *.ts > merged.ts

Warning: The binary method assumes files are in correct alphabetical order and all have the same codec parameters. If your segments are numbered with leading zeros (segment_001.ts, segment_002.ts), alphabetical order works. Without leading zeros, segment_10.ts sorts before segment_2.ts, causing playback errors. FFmpeg's concat demuxer (Method 2) is more reliable.
