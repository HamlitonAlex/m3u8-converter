视频文件太大怎么压缩？2026年无损压缩完整指南

2026年5月  |  阅读: 8 分钟

省流版：想要大幅度压缩（文件变小 50%-90%）→ 用 HandBrake（方法二）。只想重新封装不重新编码（减小 5-15%，但无损）→ 用 FFmpeg -c copy（方法一）。不想装软件 → 在线压缩工具（方法三）。

为什么视频文件会这么大？

很多人想不通：为什么一个 10 分钟的手机视频占了 2GB 空间？答案藏在三个参数里：

  • 分辨率：4K 的像素数是 1080p 的 4 倍，文件体积也是 4 倍起步
  • 码率：码率越高画质越好，但文件也越大。很多设备默认用高码率录制，比如 iPhone 的 4K 视频码率高达 50Mbps
  • 编码格式：老旧的 H.264 文件体积是新编码 H.265 的 1.5-2 倍。同样的画质，换一个编码格式文件就能小一半

方法一：FFmpeg 无损重新封装（最快）

如果你只想"换一个容器"而不重新编码视频流，用 -c copy。这不会改变画质，但能把一些老旧容器格式的开销去掉，小幅减小体积。

# 无损重新封装：TS → MP4（通常能减少 5%-10%）
ffmpeg -i input.ts -c copy -movflags +faststart output.mp4

# MKV → MP4，保留最佳流
ffmpeg -i input.mkv -c copy -map 0:v:0 -map 0:a:0 output.mp4

注意：-c copy 不会改变编码，所以如果原视频是用 H.264 拍的，输出仍然是 H.264。文件体积只减少了容器开销部分，不会大幅缩小。

方法二：HandBrake 重编码压缩（最推荐，效果最好）

HandBrake 是开源免费的视频转码工具，支持 Windows / Mac / Linux。它能用 H.265（HEVC）编码重新压缩视频，你几乎看不出画质差别，但文件能缩小 50-70%。

HandBrake 压缩步骤

  1. 下载安装 HandBrake
  2. 打开视频文件
  3. 在「Preset」中选择 Fast 1080p30（通用快速）或 HQ 1080p30（高质量较慢）
  4. 在「Video」标签下，编码器选 H.265 (x265)，质量滑块调到 RF 22-24（数值越大压缩越狠，22 是肉眼无损的平衡点）
  5. 点击「Start Encode」开始压缩

方法三：FFmpeg 命令行重编码（最灵活）

如果你习惯命令行，FFmpeg 可以精确控制每一个参数：

# H.265 硬件加速压缩（Intel GPU, 速度极快）
ffmpeg -i input.mp4 -c:v hevc_qsv -preset veryfast -crf 23 -c:a copy output.mp4

# H.265 软件编码压缩（CPU, 画质最好）
ffmpeg -i input.mp4 -c:v libx265 -preset medium -crf 22 -c:a aac -b:a 128k output.mp4

# 只改变分辨率来缩小体积
ffmpeg -i input.mp4 -vf scale=1920:-1 -c:v libx264 -crf 21 -c:a copy output.mp4

参数速查：-crf 控制质量（越小越好，18-28 是实用范围），-preset 控制速度（ultrafast 到 veryslow，越慢压缩效果越好）。

方法四：在线压缩工具

适合偶尔用、不想装软件的场景。推荐几个：

  • Clideo — 免费在线压缩，支持多种格式，但有 500MB 文件大小限制
  • VideoSmaller — 极简界面，上传即压缩，适合小白
  • FreeConvert — 支持高级选项（码率、分辨率、编码器），免费额度 1GB
隐私提醒：在线工具需要将视频上传到第三方服务器。如果你的视频含有隐私内容，请用本地工具（HandBrake 或 FFmpeg）。

常见问题

压缩后的视频能在手机上播放吗？

如果输出为 MP4 + H.264 编码，所有设备都能播放。H.265（HEVC）在较老的设备上可能不支持——iPhone 7 以上和近三年的 Android 手机一般没问题。

能不能把视频从 4K 压缩到 1080p？

能。在 HandBrake 的「Dimensions」标签里把分辨率限制为 1920x1080 即可。这是压缩效果最明显的方法——4K 降到 1080p，体积通常减少 60%-80%，但在手机上看不出太大差别。

压缩需要多长时间？

完全取决于视频时长、编码器选择和你的电脑配置。10 分钟的 1080p 视频，用 HandBrake H.265 medium 预设，普通电脑大概 15-30 分钟。
