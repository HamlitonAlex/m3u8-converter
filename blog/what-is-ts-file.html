What is a TS File? Complete Guide to MPEG Transport Stream

Published: May 2026  |  Reading time: 4 min

TS = Transport Stream

A TS file (file extension .ts) is an MPEG Transport Stream — a container format designed for broadcasting and streaming video. Unlike MP4, which is optimized for storage, TS is built for transmission: it can be read while it's still being received, recovers gracefully from errors, and splits naturally into small chunks.

Why Streaming Sites Use TS Files

When you watch a video online, the site rarely sends you one big MP4 file. Instead, it sends hundreds or thousands of tiny TS files, each containing 2–10 seconds of video. This is called HLS (HTTP Live Streaming), and the TS format was chosen because:

  • Error recovery — If one chunk is corrupted, only a few seconds are lost. The player continues from the next chunk
  • Instant start — The player loads just one chunk and starts playing. It doesn't need the whole file
  • Adaptive quality — The player can switch between 720p and 1080p TS chunks mid-stream as your internet speed changes
  • CDN cache-friendly — Small files cache well on CDNs (Cloudflare, Akamai), delivering fast load times worldwide

How to Convert TS to MP4

TS files can be converted to MP4 instantly without quality loss using FFmpeg:

ffmpeg -i "video.ts" -c copy -bsf:a aac_adtstoasc "video.mp4"

The -c copy flag copies the video stream without re-encoding — it takes seconds and preserves the original quality. See our complete TS to MP4 guide for detailed instructions.

How to Merge Multiple TS Files

If you have many TS segments from a download, you can merge them:

Windows (Command Prompt):

copy /b *.ts merged.ts

Mac / Linux:

cat *.ts > merged.ts
