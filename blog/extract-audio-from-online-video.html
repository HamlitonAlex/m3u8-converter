如何从在线视频中提取音频？5种免费方法

发布：2026年5月  |  适用：Windows / Mac / Linux / 手机

什么时候需要提取视频中的音频？

很多场景下我们只需要视频中的声音部分：想保存一首 MV 的背景音乐、提取教程视频中的讲解录音、制作播客素材、或者只是想在没有画面的情况下听内容。以下是五种完全免费的方法，从命令行到图形化工具，适合不同需求的用户。

方法一：FFmpeg 命令行（最快、最高效）

FFmpeg 是提取音频的最强大工具，一行命令即可完成。如果还没安装，参考我们的 FFmpeg 安装教程。

提取为 MP3 格式

ffmpeg -i "视频文件.mp4" -vn -c:a libmp3lame -q:a 2 "输出音频.mp3"

参数说明：-vn 表示不要视频轨，-c:a libmp3lame 使用 MP3 编码器，-q:a 2 设定音质（0=最高，5=标准）。

提取为 AAC 格式（更小体积）

ffmpeg -i "视频文件.mp4" -vn -c:a aac -b:a 192k "输出音频.aac"

提取无损原始音频（WAV）

ffmpeg -i "视频文件.mp4" -vn -c:a pcm_s16le "输出音频.wav"

WAV 格式无损，但文件较大，适合需要后期编辑的场景。

批量提取多个视频的音频

Windows 下创建 extract_audio.bat：

@echo off
for %%i in (*.mp4 *.mkv *.ts) do (
    ffmpeg -i "%%i" -vn -c:a libmp3lame -q:a 2 "%%~ni.mp3"
)
echo 全部提取完成！
pause

方法二：用 VLC 提取（图形化、免费）

VLC 不仅是播放器，还内置了格式转换功能：

  1. 打开 VLC → 菜单栏 媒体 → 转换/保存
  2. 点击「添加」选择视频文件 → 点击「转换/保存」按钮
  3. 在「配置文件」下拉菜单中选择 音频 - MP3 或 音频 - FLAC
  4. 点击「目标文件」旁边的「浏览」选择保存位置
  5. 点击「开始」，VLC 即开始提取音频

VLC 方式的优点是免费、有中文界面、不需要命令行。缺点是转换速度不如 FFmpeg，且格式选项有限。

方法三：Audacity 录制（免费开源、可编辑）

Audacity 是一款免费开源的音频编辑软件。它的独特优势是可以通过系统音频录制电脑正在播放的任何声音——包括在线视频。

  1. 下载安装 Audacity
  2. 在 Audacity 中将录音设备设为 Windows WASAPI 或 立体声混音
  3. 点击红色录音按钮，然后播放要提取的视频
  4. 录制完成后，文件 → 导出 → 导出为 MP3/WAV

如果找不到"立体声混音"设备，可能需要安装 VB-Audio Virtual Cable（免费虚拟声卡）。

使用「快捷指令」App：搜索"视频转音频"快捷指令，添加后直接在相册中分享视频 → 选择该指令 → 自动导出音频文件到「文件」App。

常见问题

提取出来的音频和视频不同步怎么办？

使用 FFmpeg 时加入 -async 1 参数可以自动修正音视频同步问题。

为什么有些在线视频提取不出音频？

部分流媒体网站将音频和视频分离存储。先通过 M3U8在线工具 找到完整的流媒体地址再下载，可以避免这个问题。详情参考我们的 M3U8 地址查找教程。

MP3 和 AAC 选哪个？

MP3 兼容性最好，所有设备都能播放。AAC 在同等码率下音质更好，文件更小，但部分老旧设备可能不兼容。如果追求通用性选 MP3，追求品质选 AAC。
