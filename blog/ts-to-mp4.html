TS 转 MP4 完整教程（FFmpeg 无损转换）

发布：2026年5月  |  适用：Windows / Mac / Linux

为什么要转换 TS 到 MP4？

TS（MPEG-TS）是流媒体常用的容器格式，但并非所有播放器都支持。MP4 是通用性最强的视频格式，手机、电脑、电视都能直接播放。将 TS 转为 MP4 可以：

  • 在 iPhone/Android 手机上直接播放
  • 导入视频编辑软件（PR、剪映等）
  • 上传到视频平台（B站、YouTube）
  • 发送给朋友，对方不需要装特殊播放器

安装 FFmpeg

Windows

  1. 打开 FFmpeg 官网下载页
  2. 找到 Windows 部分，选择 Windows builds from gyan.dev
  3. 下载 ffmpeg-release-full.7z（推荐用 7-Zip 解压）
  4. 解压后得到 ffmpeg-x.x.x-full_build 文件夹
  5. 进入 bin 目录，找到 ffmpeg.exe
  6. 将 bin 目录添加到系统 PATH（或直接在该目录打开命令行）

Mac

打开终端，使用 Homebrew 安装：
brew install ffmpeg

Linux

sudo apt install ffmpeg（Ubuntu/Debian）
sudo yum install ffmpeg（CentOS）

基本转换命令

打开命令行（Windows：在文件所在目录的地址栏输入 cmd 回车），执行：

ffmpeg -i "视频文件.ts" -c copy -bsf:a aac_adtstoasc "输出文件.mp4"

参数说明：

  • -i：指定输入文件
  • -c copy：复制编码不重新压缩，无损且极快（10 秒内完成）
  • -bsf:a aac_adtstoasc：将 AAC 音频从 ADTS 格式转为 MP4 兼容的 ASC 格式

批量转换多个 TS 文件

Windows 批处理（将以下内容保存为 convert.bat 放在视频文件夹内）：

for %%f in (*.ts) do ffmpeg -i "%%f" -c copy -bsf:a aac_adtstoasc "%%~nf.mp4"

Mac / Linux：

for f in *.ts; do ffmpeg -i "$f" -c copy -bsf:a aac_adtstoasc "${f%.ts}.mp4"; done

常见问题

转换后视频没声音？

检查 -bsf:a aac_adtstoasc 参数是否遗漏。这个参数负责正确处理 AAC 音频。

视频时长显示不对？

TS 拼接可能导致时间戳异常。添加 -fflags +genpts 重新生成时间戳：
ffmpeg -fflags +genpts -i input.ts -c copy output.mp4

转换速度太慢？

确保用了 -c copy（无损复制，几秒完成）。如果去掉这个参数，FFmpeg 会重新编码，慢几十倍。

视频教程推荐

如果觉得命令行太复杂，也可以使用图形界面工具：

  • HandBrake（免费开源，支持 TS→MP4）
  • 格式工厂（免费，中文界面）
  • Shutter Encoder（免费，基于 FFmpeg 的图形界面）

但 FFmpeg 命令行是最快、最灵活的方式，学会后一劳永逸。
