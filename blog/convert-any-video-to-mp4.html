视频格式转 MP4 全攻略：MKV/WebM/TS/AVI 免费转换

2026年5月  |  阅读: 7 分钟

一句话结论：几乎所有视频格式转 MP4，用 FFmpeg 一条命令搞定：ffmpeg -i input.xxx -c copy output.mp4。如果遇到编码不兼容（比如 WebM 的 VP9 编码），才需要重编码。不想装软件？用在线工具也行。

为什么要转成 MP4？

MP4 是目前兼容性最好的视频格式，基本上"能开机就能播"。但很多视频来源用的是其他格式：

  • MKV：高清电影、蓝光原盘的常用封装格式。功能强大但手机和电视不一定支持
  • WebM：网页视频的默认格式（YouTube 在用），但很多播放器和剪辑软件不认
  • TS：HLS 流媒体的分片格式，录屏和 M3U8 下载后经常得到 .ts 文件
  • AVI：上古格式了，但老设备录像还在用，很多新播放器已经抛弃
  • FLV：Flash 时代的残留格式，现在基本没东西能直接播了
  • MOV：苹果的 QuickTime 格式，Windows 和 Android 兼容性差

方法一：FFmpeg 命令行（万能方案）

FFmpeg 是格式转换的事实标准。以下命令覆盖了最常见的场景：

# MKV → MP4（无损，H.264/H.265 编码适用）
ffmpeg -i video.mkv -c copy -movflags +faststart output.mp4

# TS → MP4（无损，仅改容器）
ffmpeg -i video.ts -c copy -bsf:a aac_adtstoasc output.mp4

# MOV → MP4（H.264 编码无损）
ffmpeg -i video.mov -c copy output.mp4

# FLV → MP4（H.264 + AAC 编码无损）
ffmpeg -i video.flv -c copy output.mp4

# ⚠️ WebM → MP4（VP9 不能无损，必须重编码）
ffmpeg -i video.webm -c:v libx264 -crf 22 -c:a aac -b:a 128k output.mp4

# ⚠️ 旧 AVI → MP4（必须重编码）
ffmpeg -i video.avi -c:v libx264 -crf 20 -c:a aac -b:a 128k output.mp4
-c copy 的底层原理：视频文件由"容器"和"编码流"两部分组成。容器决定文件的扩展名（.mp4/.mkv），编码流决定画质和兼容性（H.264/H.265）。-c copy 是把编码流原封不动地从旧容器搬运到新容器——就像把衣服从一个箱子移到另一个箱子，衣服本身没任何变化。这就是为什么它"无损"且"秒速"。

方法二：HandBrake 图形界面（适合不敲命令行的）

如果你不想敲命令，HandBrake 是最好的图形界面替代。操作非常简单：

  1. 打开 HandBrake → 拖入视频文件
  2. 「Summary」标签 → Format 选 MP4
  3. 「Video」标签 → 编码器选 H.264 或 H.265
  4. 点击顶部「Start Encode」

HandBrake 会自动处理编码兼容性问题，不需要你判断什么时候该用 -c copy 什么时候该重编码。

各格式详细说明

MKV 转 MP4

MKV 和 MP4 都是容器格式。大多数 MKV 文件内部用的是 H.264 或 H.265 编码——这种情况下直接用 -c copy 无损秒转。唯一需要注意的是：MKV 可能包含 ASS/SSA 字幕轨道（MP4 不支持），需要先提取字幕：

ffmpeg -i video.mkv -c copy -map 0:v:0 -map 0:a:0 output.mp4

WebM 转 MP4

WebM 内部用的是 VP8/VP9 编码（Google 开源的），而 MP4 标准只支持 H.264/H.265。所以你必须重编码，没有无损捷径。视频质量会有轻微损失，但用 CRF 18-22 的参数，肉眼几乎看不出来。

TS 转 MP4

TS（MPEG Transport Stream）是最容易转 MP4 的格式——内部几乎总是 H.264 编码。一条 -c copy 秒转，或者用 在线 M3U8 转 MP4 工具 直接下载就是 MP4。

旧格式（AVI/FLV/WMV）转 MP4

这些老格式通常使用 H.264 之前的编码（DivX、WMV 等），必须重编码。用 HandBrake 选 H.264 编码器即可。值得注意的是：旧视频分辨率通常很低（480p 甚至更低），重编码到 H.264 后体积会大幅减小（因为新编码压缩率更高）。

常见问题

转换后有画面没声音 / 有声音没画面？

通常是音频编码不兼容的问题。加上 -c:a aac -b:a 128k 强制音频重编码为 AAC 即可解决。

转换后文件反而变大了？

这说明你用 -c copy 时源文件的编码本来效率就很低。改用重编码（-c:v libx264 -crf 22）来压缩。

批量转换多个文件？

Windows 用批处理脚本，Mac/Linux 用 bash 循环。详见 FFmpeg 批量转换教程。
