How to Play M3U8 Files in VLC Media Player

Published: May 2026  |  Reading time: 3 min

VLC Supports M3U8 Natively

VLC Media Player can play M3U8/HLS streams directly — no plugins, no conversion, no extra setup. If you have an M3U8 file or URL, VLC can open it in seconds.

Method 1: Open Network Stream (For URLs)

  1. Open VLC Media Player
  2. Click Media → Open Network Stream (or press Ctrl+N)
  3. Paste the M3U8 URL into the box
  4. Click Play

VLC will start playing the HLS stream immediately. This works with live streams and on-demand video.

Method 2: Open Local M3U8 File

If you have an .m3u8 file saved on your computer:

  1. Open VLC
  2. Click Media → Open File (or press Ctrl+O)
  3. Browse to the .m3u8 file and open it

Note: The M3U8 playlist file must reference accessible TS segment URLs. If the segments are online, you'll need an active internet connection. If the playlist references local files, they must be in the expected location.

Method 3: Drag and Drop

The simplest method — just drag the .m3u8 file into the VLC window. VLC automatically detects the format and starts playback.

Troubleshooting VLC + M3U8

  • "VLC is unable to open the MRL" — Check that the URL is complete and hasn't expired. Try re-copying from the source
  • Video stutters or buffers — The TS segments may be loading slowly. Try increasing VLC's network cache: Tools → Preferences → Input/Codecs → Network Caching → set to 5000ms
  • Only audio plays, no video — The stream may use a codec your VLC version doesn't support. Update to the latest VLC
  • Playlist stops after one segment — Some M3U8 files are poorly formatted. Try our online player which handles these edge cases better
