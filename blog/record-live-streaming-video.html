如何录制在线直播视频并保存到本地（5种方法详解）

发布：2026年5月23日  |  适用：Windows / Mac / Linux

为什么需要录制直播？

直播间的内容往往是"一次性"的——主播下播后，回放可能不会保留。无论是想保存重要会议、在线课程、游戏直播还是演出回放，掌握直播录制技能都能让你不错过任何精彩内容。本文整理了5种录制在线直播的主流方法，从免费开源方案到专业级工具，覆盖不同使用场景。

方法一：OBS Studio（推荐）—— 免费开源、功能最强

OBS Studio 是目前最受欢迎的开源录屏和直播推流软件，完全免费，支持 Windows / Mac / Linux。它不仅能录制屏幕，还能捕获特定窗口、浏览器标签页，甚至摄像头和麦克风。

OBS 录制直播步骤

  1. 前往 obsproject.com 下载并安装 OBS Studio
  2. 打开 OBS，点击左下角 "+" 号创建"场景"，例如命名为"直播录制"
  3. 在"来源"区域点击 "+"，根据需求选择：
    • 显示器采集：录制整个屏幕
    • 窗口采集：只录制浏览器或播放器窗口
    • 浏览器：OBS 内置浏览器直接打开直播页面
  4. 点击右下角"设置" → "输出"，设置录制格式为 MP4 或 MKV（建议 MKV，防意外中断丢失文件）
  5. 在"视频"选项中设置输出分辨率和帧率（一般 1080p / 30fps 足够）
  6. 回到主界面，点击"开始录制"即可

优点：完全免费、画质可控、支持多场景切换、可同时录制摄像头和麦克风。
缺点：学习曲线略高，初次配置需要花时间。

方法二：FFmpeg —— 命令行极客首选

如果你熟悉命令行，FFmpeg 是录制直播最轻量的方式。它不需要安装任何图形界面软件，一条命令搞定。

录制屏幕（Windows）

ffmpeg -f gdigrab -framerate 30 -i desktop -c:v libx264 -preset fast output.mp4

直接录制 M3U8 直播流

很多直播平台使用 HLS（M3U8）协议推流。你可以直接用 FFmpeg 捕获直播流并保存：

ffmpeg -i "https://example.com/live/stream.m3u8" -c copy -t 01:00:00 live-recording.mp4

-c copy 无损保存原始流，-t 01:00:00 限制录制时长1小时。

定时录制（Mac / Linux）

结合 timeout 命令实现定时录制：

timeout 3600 ffmpeg -i "直播流URL" -c copy output.mp4

方法三：VLC 播放器 —— 自带录制功能

VLC 不仅是万能播放器，还能录制网络流和屏幕。

  1. 打开 VLC，点击"媒体" → "打开网络串流"（或 Ctrl+N）
  2. 输入直播流地址（如 M3U8 链接），点击"播放"
  3. 在播放过程中，点击"播放"菜单 → "录制"（或按 Shift+R），VLC 开始将流保存到本地
  4. 再按一次 Shift+R 停止录制

录制文件默认保存在系统的"视频"或"VLC"文件夹中，格式为 MP4。此方法适合偶尔录制、不想装额外软件的用户。

方法四：浏览器扩展 —— 一键录制网页内容

如果你只需要录制浏览器中正在播放的直播，浏览器扩展是最便捷的选择。

  • Screenity（Chrome 扩展）：免费开源，支持录制标签页、整个屏幕、摄像头画中画
  • Loom：适合录制讲解类内容，自动上传云端
  • Vimeo Record：免费无限录制，Gmail 一键登录

安装后在浏览器工具栏点击扩展图标，选择录制范围（标签页 / 窗口 / 整个屏幕），点击开始即可。

方法五：专业录屏工具

如果需要更高级的功能（如定时录制、自动剪辑、添加标注），可以考虑以下付费工具：

  • Bandicam：轻量级，支持硬件加速，画质优秀（Windows）
  • ScreenFlow：Mac 平台最强录屏 + 编辑一体工具
  • Camtasia：录屏 + 视频编辑一体化，适合制作教学内容

录制直播的注意事项

版权问题

录制直播前请确认内容的版权归属。个人学习、研究用途通常属于合理使用范畴，但公开发布或商业使用录制内容可能侵犯版权。部分平台（如 YouTube、Twitch）在服务条款中明确禁止未经授权的录制。

存储空间

1080p 直播每小时约占用 2-4GB（取决于码率）。录制前确保硬盘有足够空间。建议使用 H.265 编码或调低码率来减小文件体积。

音频同步

有时录制后会出现音画不同步。OBS 可以在"高级音频属性"中手动调整音频延迟；FFmpeg 可以添加 -async 1 参数自动修正。

总结：哪种方法最适合你？

方法适用人群难度费用
OBS Studio需要高质量录制的用户中等免费
FFmpeg 命令行开发者、自动化脚本较高免费
VLC 播放器只需偶尔录制的用户简单免费
浏览器扩展只录网页内容的用户简单免费
专业录屏工具专业内容创作者中等付费

对大多数用户来说，OBS Studio 是最佳选择——免费、强大、跨平台。如果你只需要快速录制一段 M3U8 直播流，FFmpeg 命令行是最简单粗暴的方式。
