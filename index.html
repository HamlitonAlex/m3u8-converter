FAQ

What is an M3U8 file?▾
M3U8 is the playlist format used by HLS streaming. It splits video into .ts segments.
How to play downloaded TS files?▾
Use VLC Media Player (free), PotPlayer, or any universal media player.
How to convert TS to MP4?▾
Use FFmpeg: ffmpeg -i "video.ts" -c copy output.mp4
Are my videos uploaded?▾
No. The server merges segments and returns the file immediately. Nothing is stored.
Is there a file size limit?▾
No hard limit. Videos up to 2 hours are recommended.
