How to Use

  1. Get the M3U8 link — Find the .m3u8 URL (F12 → Network → search "m3u8")
  2. Paste the link — Paste it into the input box above
  3. Play or Download — Click Play to stream, or Download to save
  4. Playback — Open downloaded TS files with VLC or PotPlayer

How to Convert TS to MP4 (Lossless, Instant)

  1. Download FFmpeg
  2. Extract and find bin/ffmpeg.exe
  3. Run: ffmpeg -i "video.ts" -c copy "output.mp4"

-c copy = lossless, instant conversion
